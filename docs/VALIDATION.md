# 验证与资源测量

以下资源数据来自更名前的同一核心实现，供参考；品牌发布构建的体积请以 Release 文件为准。

日期：2026-10-26，Asia/Shanghai。环境：Apple Silicon，macOS 26.6.2，Swift 6.3.3，Codex CLI 0.142.1。

## 功能

- 真实官方额度查询通过；原生应用按服务返回的周额度自动更新。
- 14 项额度解析与过期处理检查通过：多分组优先级、单周窗口、主/次窗口、自动选择、空数据与布尔值拒绝、边界钳制、分数取整、过期标记。
- 导出并检查十款图标的 0 / 8 / 20 / 73 / 100% 状态，百分比位于图标内。
- 原生外观选择器显示十款；样式切换后保存，重启后保留。
- 应用重新打开时显示外观选择器。
- 设置菜单已实际展开，包含额度和重置时间、十款外观、窗口选择、刷新间隔、紧凑模式、暂停和登录项入口。
- 签名与包结构检查通过；安装版二进制与交付版 SHA-256 一致。

## 资源

| 项目 | 本次测量 |
|---|---:|
| 应用包文件内容合计 | 约 294 KB（十进制） |
| 文件系统占用 | 约 292 KiB |
| 分发 ZIP | 约 92 KiB |
| 全新启动、未打开外观窗口的物理内存 | 约 11 MB；当时峰值约 12 MB |
| 打开外观窗口后的物理内存 | 约 45–46 MB；窗口关闭后系统可能保留缓存 |
| 仅菜单栏运行的 RSS | 约 33.1–35.7 MiB |
| 约 68 秒、120 次采样的主进程 CPU | 峰值 0.3%，末次 0.0% |
| 查询子进程总 RSS 的采样峰值 | 约 71 MiB，短暂出现 |
| 采样末次查询子进程数 | 0 |
| 无查询子进程的样本 | 116 / 120 |

物理内存（`footprint`）和 RSS（`ps`）是不同指标；RSS 包含共享或可回收页面，不能把两者直接相加。子进程的 71 MiB 是本次采样所见峰值，不是保证上限，也未包含进程间共享去重。正式值会随 macOS、Codex CLI 版本、用户配置和打开的界面变化。

本应用不捆绑 Codex CLI；运行依赖机器已有的 CLI，因此 294 KB 应用体积不包含该既有依赖。未启用登录时启动，也未自动修改系统隐私授权。

Intel Mac、macOS 13–25、跨多显示器组合、系统睡眠/唤醒和低电量模式切换、登录项重启流程。相关兼容路径和节能逻辑已实现；本次未为验证而切换用户的系统状态。
