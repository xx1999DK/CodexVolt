# Changelog

## 1.0.0 — 2026-10-26

- First public release under the CodexVolt name.
- Ten switchable native themes, with the remaining percentage inside each icon.
- Codex account quota windows, reset times, manual refresh and configurable polling.
- Compact mode, light/dark appearance, low-quota colors and stale-data indication.
- Sleep-aware scheduling, low-power interval and failure backoff.
- Optional macOS login item; no bundled runtime or third-party dependencies.
- One-time migration of appearance settings from the original Codex Meter prototype.
